# Alonso Obras — amostra

Pagina de entrada feita para a **Electro Alonso / Alonso Obras** (Lisboa, Areeiro, desde 1963),
sem custo e sem compromisso, como proposta.

Um unico ficheiro HTML, sem javascript e sem pedidos a terceiros. As fotografias sao obras da
propria empresa.

Enquanto for amostra, a pagina leva `noindex` e o `robots.txt` bloqueia indexacao.
